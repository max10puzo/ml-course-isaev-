# Titanic — описание датасета

## Источник

Kaggle: [Titanic — Machine Learning from Disaster](https://www.kaggle.com/c/titanic)

## Назначение

Датасет содержит сведения о пассажирах лайнера «Титаник».  
Целевая переменная `Survived` показывает, выжил пассажир или нет:

- `0` — пассажир не выжил;
- `1` — пассажир выжил.

## Размеры данных

- `train.csv`: 891 строка и 12 столбцов;
- `test.csv`: 418 строк и 11 столбцов;
- в `train.csv` присутствует целевой столбец `Survived`;
- в `test.csv` целевой столбец отсутствует.

## Описание исходных признаков

| Столбец | Тип | Описание |
|---|---|---|
| PassengerId | int64 | Уникальный идентификатор пассажира |
| Survived | int64 | Целевая переменная: выжил (1) или не выжил (0) |
| Pclass | int64 | Класс билета: 1 — первый, 2 — второй, 3 — третий |
| Name | object | Имя пассажира |
| Sex | object | Пол пассажира |
| Age | float64 | Возраст пассажира |
| SibSp | int64 | Число братьев, сестёр или супругов на борту |
| Parch | int64 | Число родителей или детей на борту |
| Ticket | object | Номер билета |
| Fare | float64 | Стоимость билета |
| Cabin | object | Номер каюты |
| Embarked | object | Порт посадки: C — Cherbourg, Q — Queenstown, S — Southampton |

## Пропуски

В обучающей выборке имеются пропуски:

- `Age` — возраст указан не для всех пассажиров;
- `Cabin` — большое число пропусков;
- `Embarked` — несколько пропусков.

В работе используются следующие стратегии:

- `Age` заполняется медианой внутри групп `Pclass` и `Sex`;
- `Embarked` заполняется модой;
- `Cabin` удаляется, потому что доля пропусков очень велика;
- пропуск `Fare` в тестовой части заполняется медианой по обучающей выборке.

## Созданные признаки

В ходе Feature Engineering создаются:

- `Family_Size = SibSp + Parch + 1`;
- `Is_Alone` — признак того, что пассажир путешествовал один;
- `Age_Group` — возрастная группа;
- `Sex_Encoded` — числовое представление пола;
- `Embarked_Q`, `Embarked_S` — one-hot признаки порта посадки.
